# 🧮 Calculadora Científica em Python — Imersão Alura

Projeto desenvolvido como desafio da **atividade 2 da Imersão Engenharia de Software: Dev na Era da IA**, da Alura, utilizando o **Google Antigravity** como agente de desenvolvimento.

## 📌 Sobre o projeto

A proposta foi expandir uma calculadora básica em Python, adicionando funcionalidades matemáticas e científicas e explorando o desenvolvimento de software com o auxílio de inteligência artificial.

## 🚀 Funcionalidades

- Operações aritméticas básicas.
- Potenciação e cálculo de raízes.
- Porcentagens e cálculos financeiros.
- Funções trigonométricas e científicas.
- Estatística descritiva.
- Conversão entre bases numéricas.
- Histórico de operações e memória.
- Avaliação de expressões matemáticas.
- Tratamento de erros e entradas inválidas.

## 🛠️ Tecnologias e ferramentas

- **Python 3**
- **Google Antigravity** — agente de IA utilizado no desenvolvimento.
- **GitHub** — publicação e compartilhamento do código.

## ▶️ Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra um terminal na pasta do projeto.
4. Execute:

```bash
python3 calculadora.py
```

## 📚 Aprendizados

Durante o desenvolvimento, explorei o uso de agentes de IA no processo de programação, a importância de revisar o código gerado, executar testes, validar funcionalidades e manter o controle sobre as decisões técnicas.
